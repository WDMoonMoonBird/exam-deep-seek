# R2-B56 实施记录：管理员端「我的信息 + 修改密码」（与教师端同形态）

> 摘要（≤10 行）：① 需求原话：「给管理员页面添加一个修改自己密码的功能，就跟教师页面的一样：右上角头像『我的信息』，弹框可以修改自己密码」；
> ② 管理员端 `views/admin/Layout.vue` 头像下拉原来**只有**「主题/退出登录」（无「我的信息」）⇒ 本次补上：菜单项 `<UserOutlined /> 我的信息` + `a-modal`（**520 宽 / `:destroyOnClose` / `@cancel="resetPwdForm"`**）⇒ 内容交给 `<ProfileCard role="admin">`，与教师端同形态；
> ③ `components/ProfileCard.vue` 的 `role` 扩展支持 `admin` ⇒ 文案「管理员」（色调 brand，与教师同色）；**teacher/student 两分支返回值逐字不变**（⑩b 用抽取真实 computed 表达式求值验证）；
> ④ 密码表单与教师端一致（原密码/新密码/确认新密码 + `:loading="changingPwd"` + 「确认修改」），提交 `PUT /auth/password { oldPassword, newPassword }`（**不含 confirmPassword**，⑩c 断言请求体键恰为二者）；
> ⑤ 错误文案遵循 B55 口径：`errorCopyOf` ⇒ 服务端业务文案（如「原密码错误」）可上屏、其它固定「修改失败，请重试」、原始错误只进 console；成功 ⇒ 「密码修改成功」+ **清空表单并收起安全区**（`resetPwdForm`）+ loading 复位；
> ⑥ 防呆：`verify-frontend` 新增 **⑩a**（三端 Layout 结构对齐）/ **⑩b**（role 文案/色调）/ **⑩c**（抽取**真实 `changePassword` 函数体**执行：空值/不一致 ⇒ 零请求；一致 ⇒ 恰一次 PUT 且请求体键正确 + 成功清空 + loading 复位）⇒ **checks=36 failed=0 rc=0**；三条变异各自 rc=1 且还原逐字节一致。
> ⑦ 回归：前端核验（含构建）rc=0；jest w52+w61+w62 = 30/30；check-layers 141 文件 0 违规；指纹**按环境**：云上生产 29 / 本机生产 28 / 测试库 30。

## 2. ProfileCard 扩展（最小改动）
```js
// 文案：teacher/student 分支返回值逐字不变，仅新增 admin 分支
const roleText = computed(() => (props.role === 'student' ? '学生' : (props.role === 'admin' ? '管理员' : '教师')));
// 色调：admin 与 teacher 同为 brand（student 仍 accent）
const roleTone = computed(() => (props.role === 'student' ? 'accent' : 'brand'));
```
- props 文档同步为 `role('teacher'|'student'|'admin')`；**未改**模板结构、样式、名片区/资料区/安全区行为。

## 3. 管理员端改动清单（`views/admin/Layout.vue`）
- 新增导入：`UserOutlined`（图标行）、`ProfileCard`、`request`（原文件无需请求，故本次新增）、`message`、`errorCopyOf`；vue 导入加 `reactive`。
- 新增状态：`showProfile` / `pwdOpen` / `pwdForm{oldPassword,newPassword,confirmPassword}` / `changingPwd`；新增函数 `resetPwdForm()`（清空 + 收起）与 `async changePassword()`（校验 ⇒ 提交 ⇒ 成功提示 + 清空收起；异常走 `errorCopyOf`）。
- `handleMenu` 新增分支：`if (key === 'profile') { showProfile.value = true; return; }`（主题/退出登录分支不变）。
- 新增「我的信息」`a-modal`（位于 `</a-layout>` 之后、`</template>` 之前，与教师端位置一致）。

## 4. 测试与防呆
- **⑩a**：三端 Layout 均须含 ①`key="profile"` + **渲染出的**「我的信息」文本（注释不算）②`<ProfileCard` ③≥3 个 `a-input-password` 且三标签齐备 ④`request.put('/auth/password'` ⑤`:width="520"` + `:destroyOnClose="true"` + `@cancel="resetPwdForm"` + `resetPwdForm()` 函数存在 ⑥`UserOutlined` ⇒ `gaps=(none)`。
- **⑩b**：从 `ProfileCard.vue` **抽取真实 `roleText`/`roleTone` 表达式**求值 ⇒ `teacher ⇒ 教师/brand`、`student ⇒ 学生/accent`、`admin ⇒ 管理员/brand`（证明"不变"与"新增"同时成立）。
- **⑩c**：从 `admin/Layout.vue` **抽取真实 `changePassword` 函数体**，包成 async IIFE 用桩件执行三态 —— ①空值 ⇒ `put=[]` + warn「请填写密码」②两次不一致 ⇒ `put=[]` + warn「两次新密码不一致」③一致 ⇒ 恰一次 `PUT /auth/password`，请求体键 = `oldPassword,newPassword`（**无 confirmPassword**）+ success「密码修改成功」+ `resetPwdForm` 调用 1 次且三字段清空 + `changingPwd=false`。
- 变异对照（自做 + 逐字节还原）：M1 删除管理员菜单项 ⇒ ⑩a rc=1；M2 去掉 `roleText` 的 admin 分支 ⇒ ⑩b rc=1；M3 请求体塞入 `confirmPassword` ⇒ ⑩c rc=1；两文件还原后 sha256 **逐字节一致**、36/36 复绿。
