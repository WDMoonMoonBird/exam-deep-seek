# R2-B7 实施记录（运维入口「作业级造尺入库」：补第一把尺缺口）

## 摘要（≤10 行）
1. **缺口**：触发接口（`assignmentGradingController`）要求该作业已有 `grading_checkers` 里的 ready 尺子，否则 409/1011；而尺子只能由装置产物入库，此前唯一调用 `consumeChecker` 的地方是 job worker，job 又只能由触发接口创建 ⇒ **循环依赖，第一把尺无法产出**（t34/t36 的验证都靠直接调用消费函数绕过）。
2. **交付**：`server/scripts/r2b7-build-checker.mjs` —— 对指定作业真实拉起装置（`--checker-mode build-and-measure`）→ 产物经批 3 消费路径入库（`consumeChecker` + `consumeMeasureResults`，**「不写分」语义原样保留**）。
3. **授权门**：默认拒绝非测试库；生产需 `--allow-db <同名>` **且** `--allow-prod`；**拒绝发生在建连接与起子进程之前**（`REFUSED_BEFORE_CONNECT=yes` 且无 `STAGE=connect`；退出码为**数字 2**）。
4. **现场保留**：run-root 与隔离 `DSH_HOME` **不清理**，路径打印（`RUN_ROOT=` / `DSH_HOME=`）供审计与「DSH 全流程」录制。
5. **摘要行稳定**：`ASSIGNMENT` / `CHECKER_ID` / `CONSUMED` / `WRITTEN` / `NEEDS_RERUN` / `MODEL_CALLS`（含在 `SUMMARY_BEGIN…SUMMARY_END` 之间）。
6. **dry-run**：只打计划，不连库、不启动装置、不写库（verify 第 4 条实测 exit 0）。
7. **stub 闭环（零模型调用）**：造尺入库 + 消费 + 真写分（`CONSUMED=2 / WRITTEN=2 / NEEDS_RERUN=0 / MODEL_CALLS=0`），并覆盖「已有 ready 尺子 ⇒ 默认 rc=3、`--force-checker` 才重建」。
8. **测试**：新增 w22（7 例，守卫三态 + dry-run）与 w23（3 例，stub 闭环 + force）+ verify 全绿；既有测试文件零修改。
9. 安全：生产库只读指纹 before/after 逐位相同（本轮**不写生产**，真实运行由队长执行）；无新依赖；`server/prisma` 未动。
10. 未验证项与自纠见 §4/§5。

## 4 未验证项（单列）
1. **真实装置未跑**（本轮不写生产、也不消耗模型调用）：入口对真实 `scripts/dsh-grader/run.sh` 的调用仅由 dry-run 计划与参数构造覆盖；真实运行由队长执行（建议 `--limit 2` 先跑一份作业）。
2. **生产库授权路径的实际入库**：只验证到「越过守卫」（不可达 URL）；真实生产写库由队长执行。
3. **MODEL_CALLS 解析来源**：取装置 stdout 的 `MODEL_CALLS=（`n`）`；若装置未打印该行则记 0（已在记录与代码注释说明）。
4. **长跑/中断**：入口未内置信号处理（常驻形态由 `r2b5-worker.mjs` 负责）；单次运行中途 Ctrl-C 会留下现场（run-root/home 保留，符合「保留现场」设计）。

## 5 自纠清单
1. **测试隔离**：stub 用的 `checker.sample.json` 带**固定** `checker_id` ⇒ `consumeChecker` 的 upsert 会命中别的测试残留行（`assignmentId` 仍是旧的）⇒ 断言失败。已在 `beforeAll` 先删该 checker_id 的旧行；并改用**每个用例独立的 workdir**（否则上一用例残留的 `out/measure/s02.json` 会让 `CONSUMED=2`）。
2. **库名派生**：初版 `testDbUrl()` 用字符串替换 `/exam_system` ⇒ 当 `.env` 的库名不同时派生失败（dry-run 被误判为生产库而拒绝）。已改为按 URL pathname 首段替换（`toTestDbUrl`，含非法输入兜底）。
3. **失败阶段标注**：连接失败最初被标成 `stage=device`（误导）。已单独捕获连接阶段 ⇒ `CONNECT_FAILED=yes stage=connect`，便于机制级断言。
4. **退出码**：入口统一用 `exitWith()`（非数字 ⇒ 1）兜底，拒绝路径返回数字 2（沿用 t44 的教训）。
