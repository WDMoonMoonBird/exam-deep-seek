## 1 CSP 三态头值（真实中间件，双拓扑）

| CSP_MODE | Express 直供文档 | Express API | nginx 模拟文档 | 经 nginx 的 API |
| --- | --- | --- | --- | --- |
| `off` | 无任何 CSP 头 | 无 | 无 | 无 |
| `report-only`（默认） | `Content-Security-Policy-Report-Only` | RO | **无** | RO（Express 头透传） |
| `enforce` | `Content-Security-Policy` | CSP | **无** | CSP（透传） |

- 策略串与文档一致：`default-src 'self'; base-uri 'self'; object-src 'none'; frame-ancestors 'self'; frame-src 'self'; form-action 'self'; manifest-src 'self'; script-src 'self' 'unsafe-inline' 'unsafe-eval' data: blob:; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; font-src 'self' data:; connect-src 'self' ws: wss:; worker-src 'self' blob:; child-src 'self' blob:`；**无通配源、无外部 CDN 源**。
- `CSP_MODE` 非法值（`bogus-mode`）⇒ 回落 `report-only` 并告警（**绝不静默 enforce**）。

## 2 真浏览器（chromium）三态不阻断

- **Express 直供 3 条路由 × 3 态 = 9 组合**（`/exam/`、`/exam/login`、`/exam/doc`）：**0 CSP 违规 / 0 控制台「Refused to」/ 0 页面异常 / `#app` 已挂载**（`securitypolicyviolation` + console + pageerror 三路取证）。
- **nginx 模拟（无头）文档 3 态各 1 组**：页面同样正常挂载（该拓扑本无 CSP 可违规，仅验证可加载）。

## 3 ★部署拓扑核对（队长点名的三条）

1. **头是否真正到达浏览器**：Express 直供形态 ⇒ 文档与 API 都到达；**nginx 直供 SPA 文档 ⇒ 完全没有 CSP 头**（三种模式都一样）；`/exam/api` 经反代仍带 Express 的头。
2. **结论：需要 nginx 侧加 CSP 头**。建议片段（**report-only 起步**，仅加在"送 SPA 外壳"的 location，避免与 Express 的 API 头重复；队长确认后执行）：
   ```nginx
   # http{} 顶层：策略常量（日后切 enforce 只改头名）
   map $host $exam_csp_policy {
     default "default-src 'self'; base-uri 'self'; object-src 'none'; frame-ancestors 'self'; frame-src 'self'; form-action 'self'; script-src 'self' 'unsafe-inline' 'unsafe-eval' data: blob:; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; font-src 'self' data:; connect-src 'self' ws: wss:; worker-src 'self' blob:";
   }
   location = /exam/login     { try_files /exam/index.html =404; add_header Content-Security-Policy-Report-Only $exam_csp_policy always; }
   location = /exam/doc       { try_files /exam/index.html =404; add_header Content-Security-Policy-Report-Only $exam_csp_policy always; }
   location = /exam/doc/demos { try_files /exam/index.html =404; add_header Content-Security-Policy-Report-Only $exam_csp_policy always; }
   location ~ ^/exam/(teacher|student|admin)(/|$) { try_files $uri $uri/ /exam/index.html; add_header Content-Security-Policy-Report-Only $exam_csp_policy always; }
   # 灰度 1–2 天后把上述头名改为 Content-Security-Policy 即 enforce；回滚=去掉这些行
   ```
3. **三态可观测性**：头名为 `Content-Security-Policy(-Report-Only)`，值为上表策略串；`off` 完全无头。**enforce 下若不加 nginx 头，SPA 文档不受任何 CSP 约束（API 仍受）**——如实记录为"看似保护、实际未保护"。
