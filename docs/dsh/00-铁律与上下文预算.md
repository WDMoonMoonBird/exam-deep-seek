# 00 · 铁律与上下文预算（本流水线唯一治理文件）

> 适用：队长 + Agent A/B/C。用户明确要求：**不得让产物体积与读取量把上下文撑爆**。
> 违反 = 该轮交付**不合格**，退回重做（不是建议，是判据）。

## 一、上下文预算（硬上限）
1. **单任务精读预算**：≤ 15 个文件 / ≤ 3000 行。超出 → 先缩小范围，或改用 grep/脚本抽字段。
2. **报告体积**：单份报告 **≤ 300 行且 ≤ 20 KB**，**开头必须有 ≤ 10 行的「结论摘要」**。
   超长证据（原始日志、探针输出、长表格、diff）**必须外置**：放 `docs/dsh/evidence/<role>/`，报告里只写「路径 + ≤5 行摘要」。
3. **命令输出纪律**：一律 `| head -n 40` 或 `| tail -n 40`；跑测试/批改重定向进文件，控制台只回显摘要行；
   禁止 `cat` 大文件、禁止打印整份 JSON（用 `python3 -c` / `node -e` 抽字段）。
4. **禁读清单**：`node_modules/`、`client/dist/`、`tests/`（任务未要求时）、任何 `*.log` 全文、
   任何**上一轮报告的全文**（只允许读你要核验的那几行）。长文档**按章节读**（offset/limit），并写明读过的行段。
5. **禁止无界搜索**：不得 `find /`、不得无 include 过滤的全仓 grep、不得 `ls -R` 全仓。

## 二、跨轮记忆（防累积）
6. **唯一跨轮入口** = `docs/dsh/00-状态.md`（≤ 30 行，队长维护）。每轮报告归档在 `docs/dsh/`，
   **后续轮次不得回读**；需要引用时只引路径 + 行号。
7. **交接格式**：A→B 施工单 ≤ 8 条、每条 ≤ 5 行（目标/涉及路径/验收判据/风险）；B→C 交接 ≤ 10 行；C 的 verdict 摘要 ≤ 10 行。禁止散文式长交接。

## 三、证据与诚实（与上一会话的分界线）
8. 每条结论必须带 `文件:行号 + 原文` 或 `可直接粘贴的命令 + 真实输出摘要`，并标注【已实测】【读码推断】【无法核验】。
9. **上一会话的任何结论不得当证据**，只可当待核验对象（`/tmp/rejected-campaign-2026-10-11/`）。
10. 失败与未验证项必须单列；不许写「应该可以」「理论上」。

## 四、安全铁律
11. 不 npm/pnpm install、不构建、不执行学生代码或仓库业务代码。
12. 不写生产库 `exam_system`、不写 `~/.dsh/**`、不 kill DSH/Electron 进程、不占 :5173/:3000/:19387。
13. 仓库与日志零明文凭据；临时凭据 chmod 600 且用完即删。
14. 禁 `git clean/stash/checkout -- .`/`reset --hard`/`restore .`；不改 `client/dist`、`tests/`。

## 五、队长自我约束
15. 队长每轮只读：`00-状态.md` + 每个成员 ≤ 10 行的 output；**不把任何报告全文载入上下文**；只在需要裁定时按需深挖行段。

## 六、工作区归因与产物保险（2026-10-11 追加，因发现第三方写入者）
16. **归因纪律**：每轮开工前与收尾时，队长记录 `git status --porcelain` 的计数与 `client/**`/`server/**` 的改动摘要；
    流水线**只对 inScope 内的路径负责**。发现无法归因给任何成员的改动 ⇒ 记入 `00-状态.md` 的「第三方写入者」栏，
    不得声称是自己或他人所为；任何「B 是唯一写者」的表述都必须限定为「在流水线 inScope 内」。
17. **产物保险**：流水线产物（`scripts/dsh-*`、`docs/dsh`）必须保持**已提交**状态，
18. **验证窗口冻结**（2026-10-11 由 Agent C 的 R1-C 观察追加）：任何「验证/复核」任务开工前，队长必须记录被验路径的指纹
    （文件清单 + mtime + sha256 摘要），并在**验证窗口内禁止任何成员写这些路径**；确需写入 ⇒ 先完成本轮验证，再排下一轮修改
    （依赖串行，不靠自觉）。发现验证窗口内被改 ⇒ 该轮验证结论只对「记录的指纹版本」有效，必须显式声明。
    避免并行会话的 `git clean`/`git stash` 误伤；提交只允许包含 inScope 路径，绝不夹带 `client/**`、`server/**` 的他人改动。
