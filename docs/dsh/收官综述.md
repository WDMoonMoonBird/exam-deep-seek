## 6 风险与已知缺口
1. **造尺质量依赖模型**：即使 fail-closed 保证"不带病出分"，可用性受通过率影响；建议继续观察并保留"差额解释 + params 必填清单"补强提示词。
2. **canonical 的适用范围**：只用于**同一份跨遍**比对；跨份比 canonical 无意义（树摘要含文件名）。**四项不保证**（目录增删改名 ⇒ digest 变 / 跨 OS·Python 未验证 / zip 非 UTF-8 名仅同版本确定 / 时间戳不参与 digest）：逐条见 `R3.5-C-独立验证.md:57`，装置侧口径见 `R3.5-B2-收尾记录.md`。
3. **可比性颗粒度**：一把尺子＝一个 `(assignment_id, checker_id)`；跨作业/换尺后一律 `not_comparable`。
4. **产品内无闭环**：装置产物目前只在文件系统；无入库、无触发、无回写 ⇒ 教师端看不到分（R2 范围）。
5. **大 N 成本**：造尺 1 次模型调用 + N 次本地执行器（零 LLM），但 N 大时的耗时/内存未实测。
6. **两条现状缺陷仍在**：rubric 未冻结、"作业定死"未保证（§2 #15），不做这一层就不能宣称"历史成绩可复现"。
