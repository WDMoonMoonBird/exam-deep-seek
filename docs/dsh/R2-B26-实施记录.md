## 2 运行内外的 rc 不一致（②的成因，答复任务书）
- **外**（裸 shell 复现）：`STUB_MODE=field-max bash run.sh … --workdir /tmp/… ` ⇒ 实测 rc=0；
- **内**（selftest 沙箱）：同形态场景 rc=5（本轮我新增的失败用例报 `rc=5`）。
- **成因**：该桩场景的**前置夹具由 selftest 提供**（`STUB_CALL_LOG`、`DSH_GRADER_REAL_HOME`、`DSH_GRADER_BIN=stub-dsh.sh`、materials 夹具与 `实验/` 解析等），裸 shell 下缺失 ⇒ 装置走的是**不同分支**（造尺/量尺路径与失败点不同）⇒ rc 不同。
- **本轮修法（已实施于工作版 selftest）**：失败用例改为**显式构造必然失败**（`--source-dir <不存在目录>`）并**只断言证据字段**（`run-teardown.json` 存在 + `sessions_purged=false` + `keep_scene=true` + `.keep-scene` 含 `keep_days=` + `credentials_removed=yes`），**不依赖桩 rc** ⇒ 判据与夹具解耦。
