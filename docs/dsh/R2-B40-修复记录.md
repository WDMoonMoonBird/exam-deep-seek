## 1. 根因与修法
- 代码位置：`server/src/services/dshRunArchiver.js` 旧布局兜底块（③）的守卫 `if (items.size === 0 && fs.existsSync(resDir))`。
- 机制：`buildEvidenceSummary()` 里累积结果用的是 `const slugs = new Map()`；块外层是 `try { … } catch { /* ignore */ }` ⇒ `items` 未定义抛出的
  `ReferenceError` 被吞掉，**不报错、不计数**，于是：①只有 `out/results/*.model.json` 的历史运行 `submissions` 为空；
  ②`skip('results:non_json'|'results:not_result'|'results:parse_error')` 三个分类键恒 0。
- 修法（队长已落）：守卫改 `slugs.size === 0`（语义=「主源没收到任何条目时才扫旧布局」），并就地留注释说明死代码成因。
