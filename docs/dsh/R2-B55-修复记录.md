## 2. 统一出口 `composables/errorCopy.js`（新增）
- `errorCopyOf(err, { tag, action, suffix, log, win })`：**UI 文案唯一出口** —— 有 `response.data.message` ⇒ 用服务端文案（+suffix）；否则 `action + '失败，请重试'`；**任何情况**都先 `console.error('[R2-B55] ' + tag, { route, err })`。
- `reportError(err, opts)`：只要 console + 固定文案（不消费服务端文案）。`routePathOf(win)`：路由/哈希信息（非浏览器环境安全回落 `(unknown)`）。
- 设计约束：本模块**不读取 `err.message`**（避免原始 JS 错误进入 UI）——只读 `response.data.message`；零依赖（可在 node 下 import 断言）。
