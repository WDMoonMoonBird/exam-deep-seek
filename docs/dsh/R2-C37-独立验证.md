## 4. 缓存 / 开关 / 护栏（证据 244）
| 场景 | 观测 |
|---|---|
| miss（空缓存，cached） | `calls=1`、`generated=1`、`cache_hits=0`、`cost=0.00256`、缓存行 `hits=0` |
| 同键再跑 | **`calls=0`**、`cache_hits=1`、文本逐字一致、`cache_hit=true` |
| standardHash 变（尺子/冻结身份） | 键变 ⇒ **必 miss**（`calls=1`） |
| 无哈希 + rubric 文本变 | 文本键变 ⇒ **必 miss**（`calls=1`） |
| `mode=always` | 不查缓存 ⇒ `calls=1`、`cache_hits=0` |
| `mode=off` | 零调用、`reason=mode_off`、**不新写产物**（既有 summaries.json 原样） |
| 超预算 | `stopped=true`、`reason=budget_exceeded`、不落产物、`ok=true`（不抛、不影响调用方） |
| 模型失败 | `failed=1`、`written=0`、`reason=all_failed`、不写产物 |
> 口径（读码 + 实测）：`contentKeyOf` 有 `standardHash` ⇒ `sha256(std:+hash+|q:)`；否则有 `rubricSha256` ⇒ `sha256(rubric:+hash+|q:)`；都没有才用 rubric 文本（截断 4000 字）⇒ **缓存失效由冻结身份驱动**。
