## 5 findings（阻塞）与观察
1. **F-C4-1（中危，真实）** `test/unit/infrastructure/persistence-repositories.test.js › findScoreContext → select 白名单形状` 红：期望 `{type:true}`、实际 `{type:true, maxScore:true}`。归因：48cfd7b 为 G2 在 `submission.repository.js` 增加 `maxScore`，该单测本波未同步（**pre-R3 12/12 绿**）。影响：仓库标准 `npm test` 会红 ⇒ "全量回归绿"不成立。**最小修复：同步期望（1 行）**。
2. **F-C4-2（中危，真实，US-B5 AC1 缺口）** 教师审核页仍以 `assignment.mode==='practice'` 驱动行为：隐藏「一键审核全班/一键发布全班」（ReviewClass.vue:47）与整个底部审核栏「保存审核/发布成绩」（ReviewDetail.vue:153）、状态文案与「练习模式」标签分支；后端仍下发该值（review/summary.js:108/136）。新建作业恒 `exam` ⇒ 新数据不受影响，但**历史 practice 作业仍按 mode 走分支**，与 AC1/AC2 不符。修复建议：改由三开关/状态驱动标签与按钮可见性，或明确记录为不入期的 P2 并改验收口径。
3. **O-C4-1（低-中，既有观察，非回归）** 非 zip 上传返回 **500 + 内部文案泄漏**（`服务器错误: ADM-ZIP: Invalid or unsupported zip format…`），冻结树与 pre-R3 **逐字相同**；穿越包/缺文件路径正确（400 + 零写入 + 回滚）。建议把 ADM-ZIP 签名并入 `isClientError` → 400 +「压缩包内容非法」。
4. **F1 回归确认**：冻结 `5edf307` 探针红 → live `e71bf8d` 探针绿（score=91），独立套件 18/18；`canStudentSeeScore` 收敛为"仅 published"，与 `student/view.js` 既有规则一致（US-B6 AC3 不变）。详细窄口径复验由 t15/C5 完成。
