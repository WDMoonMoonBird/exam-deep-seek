## 2 子路径部署铁律（BASE_URL）
- 本页**不存在任何裸根路径**：不引用图片/字体等静态资源，不拼接 `/assets/...`，不写 `href="/..."`；所有请求都经既有 `request`（axios base）发出 ⇒ `grep -c BASE_URL client/src/views/admin/GradingRuns.vue` = **0**（无资源引用 ⇒ 无需要 `import.meta.env.BASE_URL` 之处）。
- 若后续在本页加入静态资源或路由链接，必须写成 `import.meta.env.BASE_URL + "..."`（route-link 已由 vue-router 的 base 处理）。
