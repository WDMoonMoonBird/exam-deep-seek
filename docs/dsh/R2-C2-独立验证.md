## 4 W3 stale 判定与重评比对
- `decideStale`：相等 ⇒ `{stale:false, reasons:[]}`；rubric 变 ⇒ `['rubric_hash_mismatch']`；rubric+standard 都变 ⇒ `['rubric_hash_mismatch','standard_hash_mismatch']`。
- **reason 名与 `scripts/dsh-checker/check.py` 的 `stale_check()` 完全同名**（`rubric_hash_mismatch` / `standard_hash_mismatch`）⇒ 两侧 stale 语义同源。
- 重评路径：`projectReviewController.js:199-212` 在进入评分之前取快照 → `resolveSnapshot` → `decideStale(stored=curEnv.grading.rubricHash/standardHash, current=textSha256(std.rubric)/std.standardHash||standardPackSha256(questionId))`；不一致且无 `?confirm=1` ⇒ **409 / code 1010 / data.code=`RUBRIC_STALE_REQUIRES_CONFIRMATION`**，`?confirm=1` 放行并 logger.warn 留痕。
