## 3. 竞态：结构对照 + 动态证据 + 局限（证据 266）
- **改前（`git show 157653d^:client/src/App.vue` 原文）**：`<router-view v-slot="{ Component, route }"><transition :name="route.meta.transition || 'page-fade'" mode="out-in"><component :is="Component" /></transition></router-view>` ⇒ **顶层**路由组件被 out-in 过渡包裹（B52 只改了 teacher/admin 两处 Layout，漏了这处）。
- **改后**：`<ErrorBoundary><router-view v-slot="{ Component, route }"><ErrorBoundary :reset-key="route.fullPath"><component :is="Component"/></ErrorBoundary></router-view></ErrorBoundary>`（无 transition）。
- **同类动态证据（我方 C40/t37 真 Chrome，证据 255）**：路由级 transition + 组件解析失败 ⇒ 右侧整块空白且**后续导航也空白**（A5）；去 transition + 边界 ⇒ 正常渲染、后续导航可用（B4）。区别仅在于触发路径（chunk 404 vs 本批 `parentNode` 竞态）——同属"过渡操作已移除/未就绪节点"类。
- **★局限（如实）**：`Cannot read properties of null (reading 'parentNode')` 属**时序/浏览器相关**，非稳定触发；本次自建 harness 两次尝试（await push 版 / 不 await + 限时版）均未在预算内取到样本（第一版挂死、第二版后台超时）⇒ **未复现 ≠ 不存在**；建议实机用 `npm run dev` + DevTools + 网络节流 + 快速点菜单循环（见 §8）。
