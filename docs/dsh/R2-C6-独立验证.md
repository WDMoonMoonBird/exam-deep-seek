## 1 方法
- 逐例探针：对**每一个**用例单独起一个 `t31-tcp-conn-probe.py 19399 <out.json> 12` 监听窗（1s 后发命令），用例结束再取 `accepted` 计数 ⇒ 每个用例的"是否连库"独立成证据，而不是一个总数。
- 拒绝态用假 URL（`mysql://u:p@127.0.0.1:19399/exam_system`）与**真生产 URL**各跑一遍；放行态只用假 URL（写路径）与真生产 **dry-run**（只读）。
- 白名单与授权函数断言：直接 import 两个脚本（不连库）调用 `assertApplyAllowed`/`assertDbAllowed`。
- 安全：未对生产库执行任何写操作；未跑禁令命令；未占 :5173/:3000/:19387。
