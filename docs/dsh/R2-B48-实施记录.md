## 2. 开关与预算语义
| 项 | 值 / 行为 |
|---|---|
| `DSH_SUMMARY_MODE` | `off`（不生成、不写产物、零调用）/ `cached`（**默认**：命中缓存跳过、miss 生成）/ `always`（无视缓存重新生成）；非法值回落 `cached` |
| `DSH_SUMMARY_MAX_COST` | 元；默认 **1.0**；每份累计 `costOfTokens()`（平台价目；**未登记型号按价目表最高 peak 档保守估算** ⇒ 护栏在未知型号下仍可信）；超限 ⇒ `stopped=true/reason=budget_exceeded`，**已生成的部分照写、后续不再生成**，分数与判据不受影响 |
| 失败语义 | 模型失败/坏 JSON/表缺失/store 异常 ⇒ 该 slug **不写**；全失败 ⇒ 不写产物文件；`runSummarySession` 永不抛出 |

## 3. 缓存键与失效（自然失效，无需清理任务）
- `content_key`：优先发布冻结快照 `standard_hash`（缺 ⇒ `rubricSha256`，再缺 ⇒ rubric 文本前缀 digest）⇒ **rubric/尺子内容变化 ⇒ 键变**；
- `result_digest`：只取 `(分项 id, 判定, 得分/满分)` 排序后 digest（与判据**文案**无关 ⇒ 文案微调不会整体 miss）；
- `summary_key = sha256(content_key | result_digest)` ⇒ 内容或结果任一变化即 miss（W65-5 断言 rubric 变必 miss + 同输入稳定）；
- `hits` 命中计数（审计"缓存省了多少次调用"）；旧行保留作审计，不参与命中。
