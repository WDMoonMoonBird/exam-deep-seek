## 3 顺带修掉的真缺陷（批 1 遗留）
- 现象：`backfill-snapshots.js --apply` 报 `Raw query failed. Code: 3140 Invalid JSON text` —— `rubric_snapshot` 是 **JSON 列**，原实现把 `questions.scoring_rubric`（TEXT）直接拷进去。
- 修法：改用 `JSON_OBJECT('rubric', …, 'rubricItems', …, 'rubricSha256', CONCAT('sha256:', SHA2(…)), 'capturedAt', …, 'backfilled', TRUE)` ⇒ 与「发布时快照」同形状，且哈希与平台 `textSha256` 同口径（utf8 文本 sha256）。
- 反证：修后 `--apply` 成功、二次 `MATCHED=0`；批 1 的 w8 单测（断言 apply ⇒ rc∈{0,3}）随之由 rc=1 恢复为 rc=0。
