# R2-B47 修复记录：复审页「返回」后空白（U-1）+ 教师端列表服务端分页与字段最小化（U-2）

> 摘要（≤10 行）：① **U-1 根因**：教师「班级复审 → 点学生（`review/project/:submissionId`）→ 点「← 返回」」走裸 `$router.back()`；
> `Layout.vue` 用 `<transition mode="out-in">` 包 `router-view`（**无 keep-alive**）⇒ 返回即**重新挂载** `ReviewClass.vue`，而它的 `fetch()` **没有 try/catch/finally**：
> 请求一旦失败/抛错就永远走不到 `loading.value = false`（该语句在 await 之后裸置）⇒ 页面停在加载态/空白，只能手动刷新；
> 叠加 `const classId = +route.params.classId`（setup 期一次性捕获）⇒ 复用组件时还会用错参数。② **修法**：返回落点确定性（上一跳在复审流内才 back()，否则显式 `/teacher/review` 兜底）、
> 参数改为 `computed`（请求时读 route）+ 路由重入 `watch`、`fetch` 一律 try/catch/**finally 必复位**、失败清空并进入**错态（可读原因 + 重试）** ⇒ 任何情况不白屏；同族 7 个页面一并处置（见 §3）。
> ③ **U-2**：`/teacher/students` 等 4 个教师列表接口此前**全量返回**（前端切片）⇒ 现支持 `page/pageSize`（默认 20、上限 100）返回 `{list,total,page,pageSize}`；
> **不传参数仍返回全量数组（向后兼容）**；`Students.vue` 改为服务端分页。④ **字段最小化**：`/teacher/students` 收紧为显式 select（去掉了 class/school 全列），键集合白名单 + 负例断言（无 password/hash/手机号/证件号）。
> ⑤ **防呆**：`verify-frontend` 新增 ⑥a/⑥b/⑥c（loading 复位 / 空态 / 路由参数来源与重入），三者在变异下均 **rc=1**，还原逐字节一致。
> ⑥ 复跑：verify-frontend（含构建）**13/13 rc=0**；w63 5/5、w64 3/3、w62 9/9、w61 8/8、w52 13/13；check-layers 0 违规；clean-env 指纹 `TABLE_COUNT=28`。

## 4. 防呆断言（`client/scripts/verify-frontend.mjs` ⑥）与变异对照

- 覆盖：13 个请求页；豁免清单显式（仅 Layout.vue）。
