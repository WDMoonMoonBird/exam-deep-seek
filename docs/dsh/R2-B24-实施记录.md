## 1 后端实现要点（server/src/controllers/adminGradingRunsController.js）
```
GET /api/admin/grading-runs?assignmentId=&status=&type=&sessions_purged=&page=&pageSize=&order_by=&order=
  ⇒ { items:[{ id, type(worker|build), archive, job_id, assignment_id, assignment_title, checker_id(脱敏·截断),
                measured, unmeasurable, skipped, written, failed, device_exit, elapsed_ms,
                sessions_purged, keep_scene, home_policy, source, created_at }], total, page, pageSize,
       source:{ table:'grading_job_runs', archives_root:'<DSH_GRADER_RUNS_ROOT|/srv/grader/runs>' } }
GET /api/admin/grading-runs/:id           # id = job-<n> | archive-build-<assignmentId>-<ts>
  ⇒ { run, teardown_json(全量), submissions(逐份摘要，来自归档 evidence-summary.json), submission_counts,
       logs:{ stdout:{present,tail(≤200 行),truncated,missing_reason}, stderr:{…} }, read_only:true }
GET /api/admin/grading-runs/:id/log?kind=stdout|stderr|run   ⇒ text/plain（脱敏；缺失时返回说明性文本，不 404/500）
```
- **只读**：仅 `prisma.$queryRawUnsafe('SELECT …')` + 文件读取；测试 W56-6 断言不含 `$executeRaw*` 与 `fs.writeFileSync/rmSync/mkdirSync/appendFileSync`。
- **脱敏**：`maskSecrets()` 把 `sk-[A-Za-z0-9_-]{4,}` ⇒ `sk-****`（日志、详情、下载三条路径都过；checker_id 亦脱敏截断）。
- **穿越防护**：`safeArchiveDir()` 校验「单层 + `^[A-Za-z0-9._-]+$` + resolve 后仍在根内」；非法 id 一律 400；`log?kind=` 走白名单映射（`etc-passwd` 之类直接 400）。
- **鉴权**：挂载点在既有 `/api/admin`（app.js:96）之下 ⇒ 由既有 admin 路由层统一鉴权（本模块不重复加守卫；挂载完成后未登录即被拒）。
- **不 500**：归档根不可读 ⇒ 日志告警 + 返回空列表；表不可读 ⇒ 退化为「仅归档视图」；日志缺失 ⇒ `present:false` + `missing_reason`。
