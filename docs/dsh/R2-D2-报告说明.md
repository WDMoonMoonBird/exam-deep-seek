## 1 数据来源（唯一输入，不由本任务生成）
- 输入：`docs/dsh/experiment2-export.json`（schema `experiment2-export/1`，导出时间 2026-10-13T15:10:30.547Z，来源注记：从云上生产库只读导出）。
- assignment id = **15 / 16**（测试 1 班 classId 18 / 测试 2 班 classId 19，各 40 条，共 **80 条**）；question id = 15。
- 尺子：rulerId=4、status=ready、checker_id=`sha256:c13c71d9…1530`、boundTo=[15,16]；每条提交另带 canonical_sha256（80 条互不相同，无重复包）。
- 逐项判据：每条提交 `feedback.breakdown` 87 项（hit / miss / missing 三态，来自 checker 原文）；AI 总评：`feedback.summary.text`（80 条全有，model=deepseek-v4-flash，prompt_version=ai-summary/1）。

## 2 口径（与报告脚注一致）
- **未通过** = `breakdown[].status !== "hit"`；**失分率** = 未通过人数 / 该班人数；**得分率** = Σ条目原始分 / Σ满分（分母 = 87 项满分之和 = **97**，平台 max_score=100 的差额 3 分不在 87 项覆盖内）。
- 分数统计用 `aiScore`（平台 INT 列，与教务可见口径一致）；σ = 总体标准差（÷n）；分位数 = 线性插值（Excel QUARTILE.INC 同口径）；分布分档 = 80–84 / 85–89 / 90–94 / 95–100（整数分段）。
- **6 包 A–F** = 按条目 title 前缀 `1.–6.` 归并的六个考核模块：A=1.x 环境配置(12 项/20 分)、B=2.x JavaBean(7/10)、C=3.x 页面跳转(14/16)、D=4.x 参数绑定(31/34)、E=5.x 响应与 JSON(15/12)、F=6.x JSP(8/5)。若教研口径的「包」另有定义，改脚本顶部 `PACKAGES` 即可，其余自动重算。
- 评语对照按「该生失分最多的包」归类（并列取失分权重），两班并排；0 未通过项者单列「无未通过项」组（13 人）。全量 80 条另有表格与 XLSX sheet。
- 两种 **Δ 方向不同**：包表 Δ = 得分率差（正 = 2 班更高）；项表/图 Δ = 失分率差（正 = 2 班失分更多），单位 pp。

## 3 四条数据告警（报告脚注同步可见，均为输入数据事实，脚本不改数）
1. `summary.facts.failed_items` 被截断为 12 条：14/80 ⇒ 逐项失分率一律以 `breakdown.status` 为准（已核对为完整未通过集合的超集）。
2. `raw_score` 与 `aiScore` 不等（INT 列截断 0.5）：13/80 ⇒ 分数统计用 aiScore，包/项得分率用原始分。
3. 87 项满分合计 97 ≠ 平台 max_score 100 ⇒ 得分率分母一律 97。
4. `finalScore` 非空 0/80（教师未定案）⇒ 全部以 aiScore 呈现。

## 4 如何重跑（一条命令；不连生产库、不写库、无网络）
```
node scripts/report/experiment2-report.mjs            # 生成 HTML + XLSX 到 docs/dsh/
node scripts/report/experiment2-report.mjs --check    # 只校验：输入合法 + 报告未过期（rc=0/1/2）
node scripts/report/experiment2-report.mjs --selftest # 反硬编码自证：变异输入 ⇒ 指纹必须变化（临时目录，自动清理）
```
- 退出码：0 = 成功/一致；1 = 报告与输入不一致（过期）；**2 = 输入缺失/非法（明确报错，绝不回退到任何数据源）**。可用 `--input`/`--out-dir` 指定路径（`--input` 指向不存在文件时 rc=2）。
- 报告内嵌 `<script type="application/json" id="report-metrics">` 指纹（不含生成时间，同输入必同指纹）；`--check` 用「当前输入重算的指纹 vs 报告内指纹」判定是否过期。
- 分数/失分率全部由输入推导：脚本内无任何字面量分数（`--selftest` 以「改写一位学生分数 ⇒ 指纹变化且 HTML 同步变化」自证）。
- 边界：只读输入 + 只写 `docs/dsh/experiment2-report.{html,xlsx}`；不 import 任何 DB/HTTP 客户端；不改 `client/**`、`server/**`、`client/dist/**`；不部署。
