## 1. 脚本与参数（`server/scripts/gen-ai-summary.mjs`）
```bash
# dry-run（默认，不写库；逐份打印 usage/费用与计划）
node scripts/gen-ai-summary.mjs --assignment <id> [--limit N] [--json]
# 单份写入（生产由队长授权后执行；先 dry-run 看 ROW 与费用）
node scripts/gen-ai-summary.mjs --submission <id> --apply
node scripts/gen-ai-summary.mjs --assignment <id> --apply --max-cost 1.5 --max-tokens 2500 [--force]
```
- 参数：`--assignment/--submission/--limit/--model/--max-tokens(默认 2000)/--max-cost(默认 5 元)/--apply/--force/--json`；测试可注入 `--base-url`（脚本 POST `<base-url>/v1/chat/completions`）。
- 读数据：**平台 Prisma**（submissions + assignment_questions 的 rubric 快照，缺快照回落题库活值；`--from`/`mysql CLI` 一概不用 ⇒ 避免原型踩过的转义坑）。
- 写库：`prisma.submission.update({ data: { aiFeedback } })` —— **只这一列**；`ai_feedback` 既有键（source/raw_score/score_int/max_score/checker_id/canonical_sha256/breakdown/detail_* …）**原样保留**。
- 新增结构：`summary = { text, facts:{passed,total,score,failed_items[]}, model, prompt_version:'ai-summary/1', tokens:{prompt,completion,reasoning,cache_hit,cache_miss}, generated_at, truncated? }`；
  无 `breakdown` 的行**跳过**（`no_breakdown`，避免无依据编造）。

## 2. Prompt（与原型一致；三条要求保留）
- **system**：课程助教角色；要求 2~4 句、分三部分 —— ①总体结论 ②失分点及**可能原因（只能依据给出的未通过项，不得编造）** ③1 条可执行建议；**禁止逐条复述、禁止客套话**。
- **user**：`【评分标准节选（可能已截断）】`（≤1200 字，超出截断加后缀）+ `【本次结果】`（得分/满分、检查项数、通过数、未通过数）
  + `【未通过项（最多 12 条：id｜分项名｜得分/满分｜判据与证据）】` + 「请直接输出总评正文（不要 JSON/标题/列表符号）」。
- 实测：20 条未通过项 ⇒ 只列 12 条（`truncated_failed=true`，且 prompt 里**不出现**第 13 条及以后，杜绝编造素材）。

## 3. 健壮性与成本护栏
| 情形 | 行为 |
|---|---|
| `finish_reason==='length'` | 打印 `SUMMARY_LENGTH_RETRY max_tokens=A⇒B reasoning_tokens=…` 并**放大预算重试 1 次**（`max(A+1200, 1.6A)`）；仍截断 ⇒ 存文本 + `truncated:true` |
| HTTP 非 200 / 坏 JSON / 空内容 / 网络异常 | 重试 ≤2 次（退避 500/1000ms）⇒ 仍失败 ⇒ 跳过该行并记 `status=summary_error`（DB 不动），整体退出码仍 0 |
| 费用累计 > `--max-cost` | 立即 `COST_GUARD_STOP` 打印并**退出码 2**（已写入的行保留、后续行不再生成） |
| 任何情况 | **不动 `ai_score`/`final_score`/`status`**：脚本前后各读一次做 `SCORE_UNCHANGED=yes/no` 断言（不一致 ⇒ 退出码 3） |
- 费用估算复用平台价目口径（`dshSessionUsage.computeCost`，按模型 peak/idle 分档）；原型 8 次真调每份 ~750–1200 输入 token、多为缓存命中 ⇒ 80 份 ≈ ¥0.5 量级。

## 4. 展示（教师复审面板；解决「不直观」）
- **有总评**：顶部 `AI 总评` 醒目段（左描边卡片，`white-space: pre-wrap`）→ 一行依据（`本次 93 / 100 分 ｜ 71 项检查通过 68 项 ｜ 失分：P06、P24…`，>6 项显示「等 N 项」）→ **分项清单默认折叠**（`a-collapse :defaultActiveKey="[]"`，展开后仍是原分项表渲染，未重写）。
- **无总评**：回落既有分项面板（汇总行 + 分项表，`defaultActiveKey=['items']` 保持展开）⇒ **不白屏、不报错**；
  旧自然语言评语/其它 JSON/坏 JSON/空 ⇒ 原样文本或「暂无评语」（`parseCheckerFeedback` 的 `kind:'text'/'empty'` 分支不变）。
- `parseCheckerFeedback` 新增 `summary`/`failedItems`/`basisText` 字段（模块级缓存保持）；`truncated` 时在总评下方显示「因模型输出长度限制被截断，可重新生成」。
