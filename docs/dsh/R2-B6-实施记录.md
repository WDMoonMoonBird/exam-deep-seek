# R2-B6 实施记录（生产库显式授权：双重 opt-in，默认仍拒绝）

## 摘要（≤10 行）
1. **默认行为不变**：不带授权时 `--apply` 指向生产库 ⇒ `RESULT=REFUSE_PROD_DB`、**exit 2**（回滚脚本的 dry-run 无 `--allow-db` 同样 exit 2）。
2. **双重显式 opt-in**：生产库的 `--apply` 必须**同时**给 `--allow-db exam_system` 与 `--allow-prod`；只给其一仍 exit 2（拒绝原因可判定：`allow_db_required` / `allow_prod_required`）。
3. **拒绝仍在连库之前**：用不可达端口 `127.0.0.1:1` 证明——被拒时 rc=2 且输出无连接错误（若已连接必然是连接失败 rc=1）。
4. **授权不写死**：`ALLOWED_APPLY_DBS` 仍只含 `exam_system_test`；生产授权是**每次调用显式给出**（命令行开关）。
5. **回滚脚本对称**：生产 `--apply` 同样要求双开关（缺 `--allow-prod` ⇒ 既有 `db_not_allowed_for_apply` 语义、exit 2）；生产 **dry-run 保持单开关可读**（向后兼容既有 w9 断言，且仍在连库前判定）。
6. **可审计**：放行时打印 `AUDIT target_db=… allow_db=… allow_prod=… authorization=… authorized_prod=yes`。
7. **本轮只交付能力与测试**：未执行任何生产回填（放行证据只到「连接阶段」——目标是不可达端口）。
8. 新增 w20（13 例，三态 × 两脚本 + 未连库证明 + 审计行）；既有 w9 等全部保持绿；未引入新依赖。
9. verify 七段全绿（串行）：unit 48 套件/685 例；contract 3/50；三重度 17/61/21；integration 39/370；指纹；smoke 8/8。
10. 未验证项见 §4。

## 2 三态实测输出（不可达端口，绝不连真库）
### 2.1 backfill（`--apply`）
```bash
cd server
P='mysql://u:p@127.0.0.1:1/exam_system'   # 不可达：证明「被拒时未建立连接」
node prisma/scripts/backfill-snapshots.js --apply --db-url "$P"
node prisma/scripts/backfill-snapshots.js --apply --db-url "$P" --allow-db exam_system
node prisma/scripts/backfill-snapshots.js --apply --db-url "$P" --allow-prod
node prisma/scripts/backfill-snapshots.js --apply --db-url "$P" --allow-db exam_system --allow-prod
```
```
① 默认拒            RESULT=REFUSE_PROD_DB reason=allow_db_required:exam_system        rc=2
② 只给 --allow-db   RESULT=REFUSE_PROD_DB reason=allow_prod_required:exam_system      rc=2
③ 只给 --allow-prod RESULT=REFUSE_PROD_DB reason=allow_db_required:exam_system        rc=2
④ 双开关（放行）    AUDIT target_db=exam_system allow_db=exam_system allow_prod=yes authorization=--allow-db+--allow-prod authorized_prod=yes
                    BACKFILL_ERROR …（连接阶段失败：端口不可达）                    rc=1
```
- ①②③ 的输出里**没有连接错误**（`BACKFILL_ERROR` 未出现）⇒ 拒绝发生在连库之前 ✓（若先连库，不可达端口必然报连接错误）。
- ④ 只走到**连接阶段**就因端口不可达失败 ⇒ 未对任何真实库执行写操作 ✓（放行仅以「守卫放行 + 审计行」证明）。
### 2.2 rollback（`--apply` 与 `--dry-run`）
```bash
node prisma/scripts/rollback-snapshots.js --apply --db-url "$P"                                    # rc=2（无 --allow-db）
node prisma/scripts/rollback-snapshots.js --apply --db-url "$P" --allow-db exam_system            # rc=2 db_not_allowed_for_apply（向后兼容）
node prisma/scripts/rollback-snapshots.js --apply --db-url "$P" --allow-db exam_system --allow-prod  # 放行 ⇒ rc=1 + AUDIT
node prisma/scripts/rollback-snapshots.js --dry-run --db-url "$P" --allow-db exam_system          # 只读：单开关放行 ⇒ rc=1 + AUDIT(allow_prod=no)
```
