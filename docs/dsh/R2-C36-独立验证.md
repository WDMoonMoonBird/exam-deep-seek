## 3. U-1：白屏根因的独立复现（证据 240）
- **方法**：抽出 SFC `<script setup>` 体（剥 `import`；唯一改写 `import.meta.env → globalThis.__T27_ENV__`，因 `new Function` 非模块上下文）⇒ 注入桩件（`ref/reactive/computed/watch/onMounted/nextTick`、`useRoute/useRouter`、`request`、`message`、`io`、store/组件占位）⇒ 得到 `loading/loadError/list/pagination/classId/fetch` 句柄后**驱动真状态机**。
- **静态要素**：`try/catch/finally` 且 `finally` 复位 `loading`；`catch` 置 `loadError`（可读原因）；模板有错态告警 + 重试入口 + 空态（`ListPage/empty-title`）；`classId = computed(() => +route.params.classId)` + 重入 `watch(() => route…)`。
- **动态（改后）**：悬挂期 `loading=true`（不是空白）→ 失败落地 `loading=false + loadError='网络错误：请求超时' + list=0`；成功 ⇒ `list=1,total=1,loading=false,loadError=''`；`classId` 由 `5→9` 后再 fetch ⇒ URL `/teacher/review-class/9`。
- **动态（改前 `bd55edc^`）**：同一驱动 ⇒ `driven=false throwErr='网络错误：请求超时' loading=true loadError=(无该字段) list=0` ⇒ **失败即白屏 + 无错态**，与修复后形成可观测差异（U1-9/U1-10）。
- **局限**（已在探针内声明）：无 DOM/Vue 真响应式；不执行 `$router.back()`/history ⇒ 「返回落点确定性」（上一跳在 `/teacher/review*` 内才 back、否则 push 兜底）由静态断言 + ⑥ 防呆覆盖，而非我动态执行。
