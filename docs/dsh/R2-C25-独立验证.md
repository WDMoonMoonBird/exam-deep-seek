## 3. 队长追加 2（A 的 t9 预审）逐条

### 3.5 ★★老锚点复用必须真的发生（阻断级）
- **正向（真实形状）**：`aq.standard_hash` 按真实写入点形状 `'sha256:'+dirSha256(dir, ignore=[])`（`assignmentSnapshot.js:29 → snapshotHash.js:105-113`）写两侧；候选 checker 的 `assignment_ref.standard_hash` 用**装置口径**（按候选自带 `ignore=['node_modules/**']` 复算）。
  - `A0b` 三值**互不相等**（zip=1de9c64829… / snap=sha256:7a40d5d4d… / dev=sha256:f1310a323…）⇒ 口径未被混用；
  - `A1` 采纳：`checker=sha256:c41c37a… sourceAssignment=32585 sameAssignment=false`（**跨作业/跨教师**历史锚点）；`A4` `status=adopted zeroLlm=true buildCalls=0`；`A6` 全库**仅 1 行** ready、`checker_raw` 与老锚点**逐位一致**（894 B）。
- **反例（夹具造假）**：候选 `aq.standard_hash` 写成 **bare hex64**（= 标准包 zip 的 sha，最易犯的口径混用）⇒ `A8` **不采纳**；`A9` 跳过行**归因到该候选本身**：`RULER_ADOPT_SKIP checker_id=sha256:1f2a252b… assignment=32587 reason=snapshot_standard_hash_mismatch`。
- **差分对（只改一列）**：同一条候选 checker/anchor 行，仅把 `aq.standard_hash` 改回真实形状 ⇒ `A10` **采纳**、`A11` 端到端采纳且 `buildCalls=0` ⇒ 采纳/不采纳的**唯一自变量**是这一列。
- ★A 的「写 hex64 会假绿」已反向核验：**两侧都写 bare hex64 时判据 1 必然通过**（§6-O4 最小复现）⇒ **不能**用「写完 hex64 后没被采纳」证明形状守卫，必须用上面的**差分对**。

### 3.6 登记守卫（`registerRulerFromLocalChecker`）
- `B1/B2`：内容**不符**的本地 ready 旧尺（`rubric_hash` 指另一份 rubric、`standard_hash` 指另一目录）⇒ 返回 **null** + `RULER_INGEST_SKIP checker_id=… reason=rubric_hash_mismatch`；`B3` 该 content_key 在 `grading_rulers` **仍 0 行**（不污染）。

- `B5/B6`：把同一条旧尺的 `rubric_hash/standard_hash` 校准为**当前内容** ⇒ 允许登记；端到端 `status=adopted zeroLlm=true`、raw **逐字节一致**（894 B）、已绑定。

### 3.7 快照 vs 活值一致性（不会「同一 key 两种物料」）
- `SL-1/SL-2`：改活值（rubric+material 改版）后**key 不变**，且指纹里 rubric/描述 = **快照**（不含活值改版）。

- `SL-5`：**两支同内容作业**导出的 rubric/题目描述/标准包 zip **逐字节相同**（`Buffer.compare=0/0/0`）⇒ 同一 key 只有一种物料。
- `SL-6/SL-7`：无发布快照 ⇒ `reason=snapshot_missing`、`contentOk=false`、不入内容化（回落旧路径且不 fail-closed）。
