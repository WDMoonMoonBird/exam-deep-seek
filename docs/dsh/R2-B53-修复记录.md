# R2-B53 修复记录：socket.io 连错路径（客户端打根 /socket.io，实际应由 /exam/socket.io 承载）

> 摘要（≤10 行）：① **实机证据**（浏览器控制台）：反复出现 `WebSocket connection to 'wss://deadpan.asia/socket.io/?EIO=4&transport=websocket' failed`，来源 `export-*.js`/`Review-*.js`/`ReviewClass-*.js`
> ⇒ 教师端实时通道**从未连上**（同时控制台**没有**任何 chunk/模块加载错误 ⇒ 白屏另有原因，见 R2-B52）。
> ② **旧注释为何有误**：`Review.vue:201` 曾写「写死 /exam/socket.io 会落进 nginx 的 `location /exam/` 静态块拿到 SPA HTML ⇒ 永远连不上（缺陷 D2）」——
> nginx 按**最长前缀**匹配，且云上已有 `location /exam/socket.io/ { proxy_pass http://127.0.0.1:3002/socket.io/; }` ⇒ **专用 location 优先于静态块**，不会拿到 SPA HTML；
> 反而**根路径** `/socket.io/` 在 nginx 上**没有**任何 location ⇒ 必然连不上（与实机证据一致）。
> ③ **修法**：新增 `client/src/composables/socketConfig.js`（默认 `path=/exam/socket.io`，可经 `VITE_WS_PATH`/`VITE_WS_URL` 覆盖；`connect`/`connect_error` **各只提示一次**、失败绝不影响渲染），两处教师页改用它建连；
> ④ 开发环境：`vite.config.js` 增 `/exam/socket.io` 代理（`target=http://127.0.0.1:3002`、`ws:true`、去 `/exam` 前缀）⇒ `npm run dev` 也能连上。
> ⑤ 测试：`verify-frontend` 新增 **⑧a–⑧e**（含"无根路径残留""可配置""不刷屏""失败不阻塞渲染""代理就位"）⇒ **checks=26 failed=0 rc=0**；三条变异各自 rc=1 且还原逐字节一致。
> ⑥ 回归：前端核验（含构建）rc=0；jest w52+w61+w62 = 30/30；check-layers 141 文件 0 违规；指纹按环境：**本机生产 28 / 测试库 30**（云上生产=29，说明见 §4）。

## 1. 实机证据与判读
- 控制台：`wss://deadpan.asia/socket.io/?EIO=4&transport=websocket` 连接失败（多次），来源是 socket.io 客户端与两个教师页的 chunk。
- 同一次控制台里**没有** chunk/模块加载失败 ⇒ 与 R2-B52 的"右侧整块空白"是**两个独立问题**（本批只修实时通道；白屏由 B52 的自愈+错误边界覆盖）。
- 结论：教师端「已提交/已评分」的自动刷新一直没生效（用户看到的是"要手动刷新"的表象之一）。

## 2. 旧注释为何有误（更正后的事实）
- 原文（`Review.vue:201`，`ReviewClass.vue:304` 同款）：把 `/exam/socket.io` 判为**不可用**，理由是会命中静态块 `location /exam/`。
- 事实：nginx 的 location 匹配规则是**最长前缀优先**——`/exam/socket.io/`（更长、且是精确专用块）**赢过** `/exam/`；云上确实存在该专用块（`proxy_pass http://127.0.0.1:3002/socket.io/`）。
- 因此：**/exam/socket.io 可用；根 /socket.io 不可用**（无 location ⇒ 落到默认 server 块或静态块 ⇒ 必然失败）。两处注释已按此改写，并保留"最长前缀匹配"的说明以防再次误判。

## 3. 修法与配置项
| 项 | 值 / 行为 |
|---|---|
| 默认 path | `/exam/socket.io`（`composables/socketConfig.js` 的 `DEFAULT_SOCKET_PATH`，与生产 nginx 一致） |
| 覆盖 | `VITE_WS_PATH`（换 path）、`VITE_WS_URL`（换域名；缺省=同源，由 nginx/Vite 代理承担） |
| transports | `[websocket, polling]`（原样保留） |
| 可观测 | `attachSocketLogging`：`connect` 打一次 `info`、`connect_error` 打一次 `warn`（含 path 与"页面功能不受影响"）；同实例重复挂载**幂等**（WeakSet） |
| 失败不影响渲染 | `createTeacherSocket` 全包 try/catch（异常 ⇒ 返回 `null`，不抛）；两处调用的 `connectSocket()` 仅在 `onMounted` 里**同步**调用，**不 await**、不在 setup 顶层 await |
| 开发代理 | `vite.config.js`：`'/exam/socket.io' → http://127.0.0.1:3002`（`ws:true`、`rewrite` 去 `/exam` 前缀） |
