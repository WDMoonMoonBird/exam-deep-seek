## 1 死代码清除（app.js）

- **删除**：`if (!process.env.JWT_SECRET) { process.env.JWT_SECRET = randomBytes(32).toString('hex'); logger.warn(...) }` 整段（原 app.js:32-37）与随之无用的 `import { randomBytes } from 'crypto'`、以及被取代的重复告警行 `if (!process.env.JWT_SECRET) logger.warn('JWT_SECRET 未配置，使用默认密钥不安全')`。
- **替换为**：零副作用显式失败点 `if (!process.env.JWT_SECRET) throw new Error('JWT_SECRET 未配置：拒绝启动（不再生成随机密钥…）')`——不写 env、不生成任何值、不带病启动。
- **不可达性依据（C47 实测 + 本批复测）**：ESM 先求值被导入模块，`middleware/auth.js:5` 在模块加载期调用 `getJwtSecret()` ⇒ 缺/弱/短密钥当场抛错，进程在 `app.js` 兜底段之前即退出。
- 证据：w70-4 静态断言（app.js 代码内无 `randomBytes`、无 `process.env.JWT_SECRET =`、保留 throw）+ **子进程实测**（`JWT_SECRET` 置空 ⇒ 非 0 退出且 stderr 含 `JWT_SECRET`，绝无 `LOADED`）。

## 2 CSP 策略与开关

- 模块：`server/src/middleware/csp.js`（新）；接线：`app.js` 在既有 `helmet({ contentSecurityPolicy: false })` 之后 `app.use(cspMiddleware())`（其余安全头仍由 helmet 承担，避免双 CSP 头）。
- **开关**：`CSP_MODE=off|report-only|enforce`，**默认 report-only**；非法值回落 report-only + 告警（绝不静默生效为 enforce）。可选 `CSP_REPORT_URI` 才带 `report-uri`（默认不带 ⇒ 违规只进浏览器控制台，不产生 404 上报）。
- 指令集（保守，逐项可解释）：
  `default-src 'self'; base-uri 'self'; object-src 'none'; frame-ancestors 'self'; frame-src 'self'; form-action 'self'; manifest-src 'self'; script-src 'self' 'unsafe-inline' 'unsafe-eval' data: blob:; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; font-src 'self' data:; connect-src 'self' ws: wss:; worker-src 'self' blob:; child-src 'self' blob:`
- **四处放行的实测依据**（首版策略 = 无 unsafe-eval/data:，实测后逐项补入）：
  1. `'unsafe-inline'`（script）：`client/dist/index.html` 的 **5 段构建期内联脚本**（首帧主题 / Vite 现代探测 / legacy 分流 / nomodule 探测 / legacy 入口）；
  2. `'unsafe-eval'`：ant-design-vue(CSS-in-JS) 的**特性探测** `new Function("a?.b")`（产物 `index-*.js` 内唯一 1 处，被 try/catch 包住）——不拦则探测判为“老浏览器”⇒ 静态样式静默退到兼容路径；
  3. `data:`（script）：Vite 的 `import 'data:text/javascript,…'` 现代浏览器探测——不拦则 `__vite_is_modern_browser=false` ⇒ 浏览器改载 **legacy 包**（实测 enforce 模式下 violations 来源从 `index-*.js` 变为 `index-legacy-*.js`）；
  4. `'unsafe-inline'`（style）/ data:（img/font）/ blob:（worker）：Vue 运行时行内样式、图标与字体、monaco worker。
  **明确不放**：通配 `*`、任何外部 CDN 源；`frame-ancestors` 收口 `'self'`（防点击劫持）。
- 已知无害共存（未改）：Express `finalhandler` 对 404/错误响应自带 `Content-Security-Policy: default-src 'none'`（框架默认，只作用于该 404 页本身，不影响业务页面）；业务页面只由本中间件下发 CSP。

1. 完全回滚：`CSP_MODE=off`（或删除该变量）⇒ 中间件透传、不再下发任何 CSP 头（浏览器侧回到本波之前的状态）；
