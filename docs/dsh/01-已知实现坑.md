# 已知实现坑 01：`$var` 紧跟多字节（全角）字符 ⇒ unbound variable ⇒ 覆盖退出码

## 现象
- 装置在**应当以非 0 退出**的场景（例：`R3.5-B S3` 篡改 frozen ⇒ 应 `exit 3`）反而以 `exit 1` 结束 ⇒ 上层断言报「篡改未被拦」。
- 日志里出现 `line N: <奇怪的名字>: unbound variable`（名字里含着全角标点，如 `rc）`）。
- 变量**其实已设置**也会中招；`|| true`、`2>/dev/null`、`if …` 都拦不住（bash 直接中止，不是普通命令失败）。

## 最小复现（零写入，A 提供，已实测）
```bash
bash -c 'set -euo pipefail; cleanup(){ local rc=$?; echo "boom=$zz）" || true; exit "$rc"; }; trap cleanup EXIT; echo RUN_EXIT=3; exit 3'
# 实测 observed_rc=1（把全角括号去掉 ⇒ 3）
```

## 机制
- macOS 自带 bash 3.2 + `LC_CTYPE=C.UTF-8`：变量名扫描按字节进行，遇到多字节字符不会停下 ⇒ `$rc）` 被当成变量名 `rc）`（把全角字节吞进名字）⇒ 在 `set -u` 下触发 unbound ⇒ bash **立即以 1 退出**。
- 危险形态：`$name` **非** `${name}`，且紧跟的字节 ≥ 0x80（全角标点、中文、emoji、`、`、`）`、`，`、`：` 等）。
- 典型位置：**日志/证据字符串**（`echo "… exit=$rc）…"`）、`local x=$?` 后的 `echo`、`printf` 拼接。

## 修法（行为不变，仅定界）
```bash
echo "exit=$rc）"      # ✗ 危险
echo "exit=${rc}）"    # ✓ 定界
```
- 清理/收尾代码的加固三步：trap 内先 `local rc=$?` 保存原码 → 内部 `set +u` → 全程 `|| true` → 末尾 `exit "$rc"`；**任何非 0 路径必须原样返回该码**。

## 静态防线（防复发）
- 脚本：`scripts/dsh-grader/scan-unbraced-vars.sh`（只读）
  - 无发现 ⇒ `SCAN_OK files=<n>` 退 0；有发现 ⇒ 逐条 `SCAN_FINDING <file>:<line> …` + `SCAN_FINDINGS n=<x>` 退 1。
  - 扫描范围缺省 `<repo>/scripts/**`；`--path <目录>` 供正/反例自测。
- `scripts/dsh-grader/selftest.sh` 已加一条断言调用它（正例全仓 + 反例注入夹具 ⇒ rc=1）。
- 实现细节：正则 `(?<![$\\{])\\$[A-Za-z_][A-Za-z0-9_]*([\\x80-\\xff])`（只挑 `$name` 形式；`${name}` 安全）。

## 四轮误诊教训（t76→t84）
1. **症状会指向错误方向**：表现是「防篡改失效」，真因却是「退出码被 bash 中止覆盖」⇒ 先对拍**退出码**与 `unbound variable`，再谈业务断言。
2. **别在同一层反复试**：teardown 先内联（t76 61/21）、再收敛为 trap 函数（t79 83/2）、再改销毁粒度（t80 仍红）——三轮都在装置层打转；fork 实验（`DSH_GRADER_PURGE_HOME=0` 完全不销毁仍红）才证明与销毁无关。
3. **测试改动要「逐条判必要性」**：w15 的假 prisma 用**位置参数猜语义**，被新增的汇总 INSERT 误判为「领取」⇒ 真因是夹具判别力，非产品回归。
4. **把坑固化成防线**：一条字节级扫描 + 一条 selftest 断言，比任何一次口头提醒都可靠。
