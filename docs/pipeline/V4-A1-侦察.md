## 2. 项目约定（可直接照抄的样板）

### 2.1 分层与放哪（有机器门禁，放错会红）

`node server/scripts/check-layers.mjs`（在 `server/` 下跑）实测：**文件 117 / 违规 0 / 未分层待迁移 42**。规则（见 `server/scripts/check-layers.mjs:63-83` + `server/src/*/README.md`）：

| 目录 | 允许 | 禁止 |
|---|---|---|
| `domain/` | 仅同层相对路径 + 语言内置（`Date`/`Intl`/`Set` 可用） | **任何** npm 包与 node 内置（`fs path child_process http …`，见 `check-layers.mjs:26` `NODE_IO`；注意 **`crypto`/`util` 不在该正则内**，故 `projectGrading.js:19` 能 `node:crypto`） |
| `infrastructure/` | domain + 任意 npm/内置 + 本层；`bootstrap/` 是组合根豁免 | 相对路径指向 `application/`、`interface/` |
| `application/` | domain + 本层 | 基础设施类 npm、node IO、相对路径指向 infrastructure/interface |
| `interface/` | application + domain + npm | 相对路径指向 infrastructure |
| **未分层**（`services/ controllers/ routes/ utils/ middleware/ app.js worker.js socket.js constants.js`） | 不受上面规则约束，但**计入「未分层待迁移 42」指标** | §5 门禁要求「未分层待迁移数**不增**」 |

> ★**放文件的硬约束**：新建 `server/src/services/xxx.js`、`server/src/utils/xxx.js` 会让「未分层 42」→ 43（`services/` 现占 13 个）。要**零指标变化**只有两条路：① 放进四个层目录；② 放进**已存在的未分层目录的子目录**（递归计数按文件算，但父目录新子目录前缀不变、数量仍会 +）。⇒ 本报告建议 **①**（且与项目正在推进的分层方向一致）。

### 2.2 模块/导出风格（照抄样板）

- **ESM 全程**，`server/package.json` `"type": "module"`；`import` 必须带 `.js` 后缀 `import logger from '../utils/logger.js'`。
- **重导出 barrel** 样板：`server/src/infrastructure/ai/deepseek/index.js`（9 条 re-export，注释注明「保持对外导出面逐字不变」）；`server/src/infrastructure/rule/index.js:23-31`。
- **纯函数导出供单测** 样板：`server/src/services/projectGrading.js:678-700` `export function computeRuleVersionHash(question)`，注释写明「纯函数（导出供单测）；不改变既有评分逻辑」。
- **配置模块常量** 样板：`server/src/domain/services/rule/constants.js`（导出白名单数组 + 中文 JSDoc）。
- **注释风格**：中文块注释说明「为什么」+ `@param/@returns`（见 `studentController.js:18-35`）；关键论断标注日期与来源（如 `2026-08-17 并发修复`）。

### 2.3 错误处理风格

- 领域错误体系 `server/src/domain/errors.js`（`DomainError` + 子类，带 `code`）；应用层捕获并映射 HTTP。
- 基础设施/服务层：**吞异常 + 记日志 + 落状态**，绝不让调用方崩（`projectGrading.js:642-648` `markFailed`；`gradingWorker.js:186-188`）。
- 兜底常量 `server/src/constants.js` `ABNORMAL_FEEDBACK = '请联系老师'`。

### 2.4 日志风格

`logger.info({ 结构化键值 }, '中文短句')` —— 例：`gradingWorker.js:254` `logger.info({ maxConcurrent: MAX_CONCURRENT }, '评分 Worker 已启动')`；错误用 `logger.error({ err, submissionId }, '…异常')`。

### 2.5 配置读取（`getConfig` 一族）

```js
// 照抄样板：server/src/infrastructure/ai/deepseek/config.js:44-47
export async function getConcurrency() { const v = await getConfig('ai_concurrency', '16'); return +v || 16; }
```
- 语义：**DB(system_configs) 优先 → ENV 兜底**；1 分钟缓存；DB 失败回退缓存/空对象不抛（`config.js:14-25`）。
- 类版等价物（含 `set`）：`system-config.repository.js`，经 `compose()` 挂 `app.locals.configRepo`。
- ★**坑**：`adminController.js:397-435`(`getSettings`)/`:437-478`(`updateSettings`) 的 key 是**硬编码白名单**（`deepseek_api_key/deepseek_model/deepseek_base_url/ai_concurrency`）⇒ **新键 `dsh_grading_*` 无法从管理端 UI 写**，只能 DB 手写或走 ENV 兜底。
