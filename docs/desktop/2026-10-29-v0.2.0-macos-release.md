## 2. 构建

```bash
cd desktop
export PATH="/opt/homebrew/bin:$PATH"
npm run build:dist                      # client/dist → dist-desktop（390 文件）
CSC_IDENTITY_AUTO_DISCOVERY=false ./node_modules/.bin/electron-builder \
  --mac --arm64 -c.electronDist=node_modules/electron/dist
```

> **必须带 `-c.electronDist=node_modules/electron/dist`**：本机 electron-builder 在
> 「unpacking default Electron distribution」这一步会卡死（0% CPU、无子进程，等待超过 10 分钟）。
> 直接用 `node_modules/electron/dist`（已由 `node install.js` 解压好的 Electron 44.9.0）可绕过。
