# 错误页设计稿（404 / 403 / 500）

现状：系统没有固定的错误页 —— 未知路径 `redirect: '/login'`、角色不符也丢登录页、后端 `/api` 未知路径没有 404 JSON、
发版后旧标签页会白屏。本目录是三张稿与两套配色方案，**只出稿，未改任何业务代码**。

## 三页的文案与动作（定稿候选，可直接改）

### 404 页面不存在
- 说明：你访问的地址没有对应的页面 —— 可能是链接输错了，或者这个页面已经被移除。
- 额外信息：**显示你访问的地址**（等宽字体 + 复制按钮），手输地址时不用猜自己打错了哪里
- 动作：主「回到我的工作台」/ 次「返回上一页」
- 脚注：如果是手输地址，请检查拼写；从旧收藏夹进来的链接可能已经失效。

### 403 没有访问权限
- 说明：你已登录，但当前账号的身份不能打开这个页面。
- 额外信息：**当前身份卡**（头像 + 姓名 + 角色 + 学校）+ 一行「此页面需要 `教师` · 你现在的身份是 `学生`」
- 动作：主「切换到我的工作台」（按角色跳对应首页）/ 次「切换账号」
- 脚注：如果你确实需要访问，请联系管理员为你的账号开通权限。
- 与 404 的关键区别：**保留登录态**，不要再丢回登录页（现在的行为会让人以为被登出了）

### 500 服务暂时不可用
- 说明：服务器出了点问题，这次操作没有完成。稍后重试通常就能恢复。
- 额外信息：**错误编号**（等宽 + 复制，形如 `ERR-8F3C21A4`）+ 已自动重试次数与时间
- 动作：主「重试」/ 次「回到首页」
- 脚注：持续出现请把上面的错误编号发给管理员，便于定位。

## 共同设计（沿用现有设计语言）
- 居中卡片：`--card-bg` + `--card-bd` + `--radius-lg` + `--shadow-md`，最大宽 560
- 顶部真 logo（`assets/logo.svg`，即仓库根「学习中.svg」）+ 「Deadpan 判题」
- 页面底色 `--bg-canvas`；数字用等宽数字（tabular-nums）；底部三个文字链接：使用文档 / 返回首页 / 联系管理员
- 手机端（≤480）：按钮竖排满宽、卡片内边距收窄、卡片最大宽 100%
- 全部用真实令牌，浅/深色自动生效（深色稿见 `dark-404.png`）

## 落地位置（实现时改这几处）
1. `client/src/router/index.js`：`/:pathMatch(.*)*` 从 `redirect: '/login'` 改为 → NotFound 页；
   守卫里把「角色不符」单独分支到 `/403`（并把原目标存起来，登录页回跳用 `?redirect=`）
2. `client/src/api/request.js`：5xx → 跳 `/500`（或就地展示 500 卡片）；401 跳登录前给一次「登录已过期」提示
3. `client/src/main.js` + `router.onError`：捕获 `Failed to fetch dynamically imported module` → 「系统已更新，请刷新」
4. `server/src/app.js`：`/api` 未命中时 `res.status(404).json({ code: 1404, message: '接口不存在', data: null })`
5. 新增一个可复用的 `ErrorPage.vue`（props：code/title/desc + 默认插槽放额外信息 + 动作插槽），三条路由共用一个组件
