# 错误页设计稿（404 / 403 / 500）

现状：系统没有固定的错误页 —— 未知路径 `redirect: '/login'`、角色不符也丢登录页、后端 `/api` 未知路径没有 404 JSON、
发版后旧标签页会白屏。本目录是三张稿与两套配色方案，**只出稿，未改任何业务代码**。

## 三页的文案与动作（定稿候选，可直接改）

### 404 页面不存在
- 说明：你访问的地址没有对应的页面 —— 可能是链接输错了，或者这个页面已经被移除。
- 额外信息：**显示你访问的地址**（等宽字体 + 复制按钮），手输地址时不用猜自己打错了哪里
- 动作：主「回到我的工作台」/ 次「返回上一页」
- 脚注：如果是手输地址，请检查拼写；从旧收藏夹进来的链接可能已经失效。

### 403 没有访问权限
- 说明：你已登录，但当前账号的身份不能打开这个页面。
- 额外信息：**当前身份卡**（头像 + 姓名 + 角色 + 学校）+ 一行「此页面需要 `教师` · 你现在的身份是 `学生`」
- 动作：主「切换到我的工作台」（按角色跳对应首页）/ 次「切换账号」
- 脚注：如果你确实需要访问，请联系管理员为你的账号开通权限。
- 与 404 的关键区别：**保留登录态**，不要再丢回登录页（现在的行为会让人以为被登出了）

### 500 服务暂时不可用
- 说明：服务器出了点问题，这次操作没有完成。稍后重试通常就能恢复。
- 额外信息：**错误编号**（等宽 + 复制，形如 `ERR-8F3C21A4`）+ 已自动重试次数与时间
- 动作：主「重试」/ 次「回到首页」
- 脚注：持续出现请把上面的错误编号发给管理员，便于定位。

## 插画方案（两版自绘，取代纯文字的错误页）

| 方案 | 语言 | 404 | 403 | 500 |
|---|---|---|---|---|
| **A 抽象几何** | 线性图标感，克制、离界面远 | 断开的虚线路径 + 一张飘着「?」的页卡 | 身份牌 + 一把锁（锁会轻晃） | 齿轮（缓慢旋转）+ 断开的线缆与火花 |
| **B 界面隐喻** | 复刻界面元素，与手册演示同一套语言 | 空列表 + 放大镜（上下浮动） | 被锁徽章盖住的页卡 | 卡在 ~55% 的进度条 + 末尾警示牌 + 重试箭头 |

- 两版都是**内联 SVG**（约 1KB、零额外请求）、颜色全部取现有令牌 → 浅/深色自动成立；
- 带**轻微动效**（浮动 / 锁晃 / 齿轮转 / 进度条推进），已按 `prefers-reduced-motion` 关闭；
- 想直接看动效：浏览器打开 `art-a.html` / `art-b.html`（内联了真实 tokens.css 与真 logo，无需起服务）。

### 为什么建议自绘而不是用素材站
① 素材站的许可与署名要求各不相同且会变（unDraw 类最宽松、Storyset/Icons8 需署名、Blush 按作者而异），商用/校内系统要逐个核实；
② 外部插画很难保证「换品牌色 + 深浅色」都对；③ 自绘 1KB、可随设计令牌演进，也不会和系统的克制风格打架。

## 共同设计（沿用现有设计语言）
- 居中卡片：`--card-bg` + `--card-bd` + `--radius-lg` + `--shadow-md`，最大宽 560
- 顶部真 logo（`assets/logo.svg`，即仓库根「学习中.svg」）+ 「Deadpan 判题」
- 页面底色 `--bg-canvas`；数字用等宽数字（tabular-nums）；底部三个文字链接：使用文档 / 返回首页 / 联系管理员
- 手机端（≤480）：按钮竖排满宽、卡片内边距收窄、卡片最大宽 100%
- 全部用真实令牌，浅/深色自动生效（深色稿见 `dark-404.png`）

## 落地位置（实现时改这几处）
1. `client/src/router/index.js`：`/:pathMatch(.*)*` 从 `redirect: '/login'` 改为 → NotFound 页；
   守卫里把「角色不符」单独分支到 `/403`（并把原目标存起来，登录页回跳用 `?redirect=`）
2. `client/src/api/request.js`：5xx → 跳 `/500`（或就地展示 500 卡片）；401 跳登录前给一次「登录已过期」提示
3. `client/src/main.js` + `router.onError`：捕获 `Failed to fetch dynamically imported module` → 「系统已更新，请刷新」
4. `server/src/app.js`：`/api` 未命中时 `res.status(404).json({ code: 1404, message: '接口不存在', data: null })`
5. 新增一个可复用的 `ErrorPage.vue`（props：code/title/desc + 默认插槽放额外信息 + 动作插槽），三条路由共用一个组件

## 方案 C：小机器人家族（**采用**，路线 1 的成果）

一个固定角色 + 每页换一个「处境」的插画系统，替代外部 Lottie 素材。

### 角色规格（以后加页面照这个画，风格就不会飘）
| 部件 | 规格（viewBox 220×140） |
|---|---|
| 头身一体 | 圆角矩形 40×34，rx 11，填充 `--brand-600` |
| 身体 | 圆角矩形 26×22，rx 8，`--brand-600` 88% 透明 |
| 天线 | 10px 竖线 + 灯（r4.5），灯色=该页语义色，2.2s 闪烁 |
| 眼睛 | 两个 r3.4 白点；「睡着」时改成两条横线（用于 401） |
| 手臂/腿 | 3px 圆头线段；手臂角度按处境摆（举牌 / 指路 / 拿扳手） |
| 配色 | 主体 `--brand-600`；警示 `--status-warning-fg`；故障 `--status-danger-fg`；线稿 `--border-strong` |

### 每页的道具与处境
| 页面 | 处境 | 动效 |
|---|---|---|
| 404 页面不存在 | 站在**断开的虚线路径**口，举「?」牌 | 牌与页卡浮动 3.4s |
| 403 没有访问权限 | 举着**访客身份牌**，面前一把**锁** | 锁每 2.8s 轻晃一下 |
| 500 服务暂时不可用 | 拿**扳手**修**卡住的齿轮**，冒火花 + 一滴汗 | 齿轮 7s 线性旋转、火花 1.1s 闪烁 |
| 401 登录已过期 | 看着**漏完的沙漏**（闭眼） | 沙漏浮动 2.2s |
| 离线 / 维护中 / 文件太大（草图） | 断开的信号弧 + 叉 / 警告三角 / 文件 + 上传箭头 + 叉 | 同上 |

### 体积与依赖（对比外部 Lottie 素材）
- 每张 **1.60–1.91 KB**，四张合计 **7.28 KB**；外部 Lottie 单文件 293.5 KB（**约 40 倍**）
- **零播放器依赖**（Lottie 需要 lottie-web，light 版 gzip 仍约 50KB），颜色全部取现有令牌 → 深浅色自动成立
- 文案写在页面里（不是烧进图形），中文本地化零成本；动效全部在 `prefers-reduced-motion` 下关闭

预览：`art-c.html`（浏览器直接打开，可看动效）；总览见图 `overview-art-c.png`（404/403/500/401）与 `overview-art-c-strip.png`（扩展草图）。

## 外部 Lottie 素材评估（用户提供的 Page Not Found 404.json）

素材：Lottie v5.7.3，nm=ErrorPage404，1920×1280，60fps，241 帧（4.02s），46 图层，**293.5 KB**，无内嵌位图，24 个硬编码颜色（#8550fc / #380f8f / #f38346 / #f4d37e / #414042 …）。
观感：紫色笔记本电脑屏上「404 Page not found」+ 齿轮叶片 + 一个小机器人探头说「Oops! / We can't seem to find the page you're looking for. / Error code: 404」。
帧采样见 `lottie-404-frames.png`。

**结论：能用，但有四个真实代价**
1. **要加播放器依赖**：`lottie-web`（light 构建约 148KB / gzip ~50KB），或 dotlottie 的 WASM（~2MB，不可接受）；好在可按需只在 404 页懒加载。
2. **体积**：单页 293.5KB，是我们自绘 SVG（~1KB）的约 300 倍；可优化（60→30fps、剔冗余图层、数值取整）到约 120–150KB。
3. **文案烧死在动画里**：`Oops!`／`We can't seem to find the page you're looking for.`／`Error code: 404` 都是**矢量轮廓**（图层名带 Outlines），改中文必须在 AE/Lottie 编辑器里重做；即使不改文案，也和我们的中文页面不搭。
4. **配色不可换 + 授权待确认**：24 个硬编码颜色不跟随设计令牌（深色主题下会像一张亮贴纸），JSON 内无授权信息（meta=null），需回素材页确认是否可商用/需署名。

**建议**：优先「拿它当参考自绘」（零依赖、文案可换、跟主题）；若坚持用它，至少做三件事：① 确认授权 ② 用脚本剥掉文字轮廓层并重导出（体积同时下降）③ 30fps + 懒加载 light 播放器 + 深色主题加浅色底板。
