# 信息架构（Information Architecture）

> 对应 skill Phase 2。**硬约束：不改变任何路由 path 与权限模型**，只重构「展示层级、导航分组、页面骨架与上下文」。

---

## 1. 现状

| 端 | 侧栏项数 | 现状问题 |
|---|---|---|
| 管理端 | 6 项平铺 | 「组织类」与「系统类」混在一起，配置页与业务页同级 |
| 教师端 | 6 项平铺 | 高频（作业/审核）与低频（班级/学生/团队）同权重；审核入口无待办提示 |
| 学生端 | 2 项平铺 | 尚可，但作业列表→作答→成绩缺少状态贯通 |
| 全局 | 顶栏 + 用户菜单 | 用户菜单里混了「我的信息 / 切换单位 / AI 评分流程 / 使用文档 / 退出」，功能与帮助混杂 |
| 深层页 | 编辑页、审核详情页 | **没有返回上下文**，只能靠浏览器后退；同一个「审核」有两套完全不同的界面（通用题 / 实训题） |

### 2.3 层级与返回上下文规则

| 层级 | 判定 | 页头形态 |
|---|---|---|
| L1 列表 | 侧栏一级路由 | 标题 + 描述 + 主操作（**无面包屑**） |
| L2 详情/编辑 | 从 L1 进入 | 返回条（`← 返回{来源页名}`）+ 对象名 + 面包屑（角色首页 / 列表 / 对象） |
| L3 工作台 | 审核、批改类 | 返回条 + 对象名 + 状态徽标 + 右侧动作区（**面包屑省略，改用状态徽标**） |
| 弹层 | Modal / Drawer | 不产生路由、不改 URL；关闭后焦点回到触发按钮 |

> 例：`/teacher/review/:id` 的返回条显示 `← 返回评分审核 · 周子轩 / 202600104`；从班级页进入时返回文案为 `← 返回 计算机 2301 班`。

## 4. 关键流程（教师主链路）

```
题库管理           作业管理              学生端                评分审核
┌────────┐      ┌────────────┐      ┌────────────┐      ┌────────────────────┐
│ 新建题目│─────▶│ 布置作业   │─────▶│ 作答/上传  │─────▶│ 待审核队列（徽标 N）│
│ (通用/ │      │ 选题+设截止│      │ 提交       │      │  ├ 通用题逐题批改   │
│  实训) │      │ 指定班级   │      │            │      │  └ 实训题看工程包   │
└────────┘      └────────────┘      └────────────┘      └─────────┬──────────┘
                        ▲                                        │ 发布
                        │                                        ▼
                  ┌────────────┐                        ┌────────────────┐
                  │ AI 评分中   │  Worker 轮询 → AI → WS │ 学生「查看成绩」│
                  │ (进度语义)  │ ──────────────────────▶│ 分数 + 反馈     │
                  └────────────┘                        └────────────────┘
```

流程中的设计要点：
1. **AI 评分中**是可长达数分钟的状态：列表行内显示进度语义（排队中 / 评分中 / 已完成），并提供「有新结果」的显式刷新提示（WebSocket 推送不得静默跳变）。
2. **审核结果发布**是不可逆动作 → 二次确认弹窗必须写清「影响范围：N 名学生将看到分数」。
3. **学生提交**是不可逆动作 → 提交按钮需 确认 + 提交后展示回执（时间、题数、附件数）。

## 5. IA 改动清单（相对现状）

| 类型 | 改动 | 收益 |
|---|---|---|
| 分组 | 教师端 6 项拆为「教学 / 组织」两组，顺序按频率重排 | 高频入口上移，降低扫描成本 |
| 徽标 | 侧栏「评分审核」显示待审核数量 | 待办可见，减少「点进去看有没有」 |
| 上下文 | 所有 L2/L3 页新增返回条 + 面包屑（复用现有「← 返回」样式） | 深层页不再依赖浏览器后退 |
| 统一 | 通用题审核与实训题审核统一到 Workbench 壳（同一骨架、同一评分面板） | 教师只需学一次 |
| 分栏 | `/teacher/review` 增设 Tabs：待审核 / 按班级 / 已发布 | 班级视图不再是「另一个页面」 |
| 状态 | 学生端作业/成绩共享 4 状态语义（未开始 / 进行中 / 已提交 / 已评分） | 学生一眼知道下一步 |
| 命名 | 统一术语：题目（通用题）/ 实训题 / 作业 / 提交 / 评分审核 | 去掉「题库管理 vs 题目管理」类混用 |
| 帮助 | 用户菜单把「AI 评分流程 / 使用文档」下移到分隔线以下 | 功能与帮助分离 |

**明确不做**：不改 path、不改角色权限、不新增一级菜单、不做多语言切换。
