  1. 10-12评分新功能重大

    实训题评分改由 DeepSeek Harness 执行新

    评分单位从「一次 LLM 调用」改为「一份作业一次造尺、N 次量」：DeepSeek Harness 在隔离环境跑标准包与判据，带锚点校验与失败即停。

    实测数据

    同一提交重复评分命中缓存不再消耗 LLM（本次零 LLM）；分数写回平台。353 作业生产验证：62 份成绩 / 写出 59 份 / 与基线逐位一致，59 份均不低于旧分，均值 81.9 → 84.6。已上云（pm2 dsh-grader-worker）。

  2. 10-13评分体验优化

    AI 给分依据可读

    分项得分带理由；新增自然语言总评；教师侧可直接看到「为什么扣分」，并支持回填。

  3. 10-18移动端新功能

    教师端移动版上线（v1）

    工作台 / 作业 / 评分审核 / 布置作业 四页打通，手机上可完成「看进度 → 逐份审核 → 发布」；实训题审核支持文件树导航。

  4. 10-18移动端新功能

    安卓版 APK 可下载

    欢迎页新增安卓版入口，扫码安装即可用；启动直达登录页。

  5. 10-14作业新功能

    提交与评分：三个开关

    取最高 / 取最后一次成绩、是否允许补交、答案是否可见 —— 布置作业时按题型带默认值，并给出成本提示。

  6. 10-13手册体验优化

    教师手册改为「可播放演示」

    8 段真实界面复刻替代全部截图：进章节自动播放、可暂停重播；右上角「放大演示」支持要点放大与手机 2×。

  7. 10-13错误页新功能

    错误页体系与真状态码

    404 / 403 / 500 等 16 个状态页（中文、深浅色、自动重试）；未知路径与超限上传返回真实状态码。

  8. 10-13安全安全与稳定

    账号与链路加固

    改密后旧令牌立即失效；JWT 弱密钥快速失败；上传超限返回 413；新增 CSP（先观察模式）。

  9. 10-12作业体验优化

    布置作业改为一页式

    题目单选、班级带人数、起止时间默认「今天 18:00 ~ 一周后」、支持存草稿与离开确认。

  10. 10-12列表体验优化

    列表样式统一（v2）

    11 个列表页统一行高与对齐，主列改两行式（标题 + 次要信息），密度更稳、扫读更快。

  11. 10-12个人新功能

    「我的信息」卡片

    教师 / 学生 / 管理员三端同形态：头像姓名角色 + 关键字段 + 一键复制，支持展开收起。

  12. 10-11欢迎页体验优化

    欢迎页重构 + 二维码

    新的首屏结构与动效；页脚加入开源地址与站点二维码，方便扫码进入。
