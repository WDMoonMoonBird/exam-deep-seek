选择你的设备

Android · Chrome

菜单 → 安装应用

当前平台 推荐
  1. 用 Chrome 打开本页在地址栏输入校内网地址，或从通知消息打开。
  2. 点右上角「⋮」菜单，选择「安装应用」或「添加到主屏幕」部分国产浏览器文案为「添加到桌面」，效果相同。
  3. 确认「安装」，等待桌面出现 Deadpan 图标安装后与浏览器共用登录态，不会重复登录。

iOS · Safari

分享 → 添加到主屏幕

当前平台
  1. 用 Safari 打开本页微信 / QQ 内置浏览器不支持「添加到主屏幕」。
  2. 点底部工具栏的「分享」按钮若工具栏已收起，向上轻扫屏幕底部即可展开。
  3. 选择「添加到主屏幕」，点右上角「添加」iOS 当前通过主屏幕方式使用，原生 App 仍在规划中。

iOS 不提供「安装应用」入口，添加到主屏幕即为官方支持的方式。

已经安装过？ 从桌面图标打开即可，仍使用同一工号 / 学号登录。
