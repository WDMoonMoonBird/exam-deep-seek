Design Principles

不是把桌面缩小，而是按场景重排

手机上每次操作都发生在拇指、弱网和碎片时间里。37 屏都按下面五条取舍。

01

一屏一事

每屏只有一个主任务；主操作固定在底部动作条，不藏在表内或右上角。

02

数据先行

列表卡片只保留能决策的 4 个字段：状态、进度、截止、下一步动作。

03

状态显性

loading / empty / error / offline 四态完整；AI 评分这类异步结果有进度语义。

04

拇指优先

触控目标 ≥44px，主按钮高 50px；高频操作落在下半屏，危险操作需二次确认。

05

克制动效

160–320ms、只动 transform / opacity；Sheet 与页面切换模拟原生手感，尊重减少动效偏好。

Platform Strategy

一份 Vue 代码，三层复用

Web 移动端现在交付；Android 以 Capacitor 壳复用同一套 UI；iOS 只做规划 —— 苹果限制、审核成本与当前工具链决定暂不出包。

跨端一致性的三道保险

One UI, Three Shells

同一套移动组件与设计令牌，运行在三类容器里：手机浏览器、PWA 独立窗口、Capacitor WebView。差异只允许出现在系统层（状态栏高度、返回手势、文件选择），业务 UI 不写平台分支。

安全区--m-safe-top / --m-safe-bottom
返回浏览器返回 / 系统返回键统一走路由
深色跟随系统 + 手动开关
更新入口版本探测 + APK 升级提示
